Holocron is an independent, unofficial project inspired by the Star Wars universe. It is not affiliated with or endorsed by Lucasfilm Ltd. or Disney.

## Requirements

- macOS 14+, Windows 10+ or Linux
- [Python 3.12+](https://www.python.org/downloads/)
- [Ollama](https://ollama.com/download) — optional, for Keeper

Dependencies install automatically on first launch.

## Install

```zsh
git clone https://github.com/Gustxxl/holocron.git
cd holocron
python3 install.py
```

No Git? Download the ZIP from the repository page (Code → Download ZIP), unzip it and run `python install.py` inside the folder.

Then open a new terminal and run:

```zsh
holo
```

To force update:

```zsh
python3 -m core.updater
```

To remove the command:

```zsh
python3 install.py --remove
```
